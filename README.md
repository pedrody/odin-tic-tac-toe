# odin-tic-tac-toe

This project is a tic-tac-toe game, built as part of [The Odin Project](https://www.theodinproject.com/) JavaScript course, aiming to practice **factory functions** concepts.

The project is deployed via GitHub Pages, so you can easily [try it out here](https://pedrody.github.io/odin-tic-tac-toe/).
